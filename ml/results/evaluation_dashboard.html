Pertanyaan 1: Apakah sistem ini masih memakai EfficientNet-B0? Lalu kenapa ada istilah YOLO?

JAWABAN TEGAS: YA, 100% MASIH EFFICIENTNET-B0!

Model kecerdasan buatan (*classifier*) yang berjalan di server dan melakukan klasifikasi diagnosa penyakit pada daun tomat adalah EfficientNet-B0 (terletak di berkas fastapi/models/final_model.pt).

Lalu apa fungsi YOLO di sistem ini?

  • Bukan sebagai pengganti model: Sistem tidak memakai arsitektur YOLO untuk mendiagnosa citra saat aplikasi dijalankan.
  • YOLO dipakai sebagai Alat Ekstraksi Data (Data Pipeline): Dataset foto kebun dari Roboflow memiliki format anotasi YOLO-OBB (Oriented Bounding Box). Bounding box ini kita gunakan secara otomatis untuk memotong (crop) daun berpenyakit dari foto kebun yang luas dan berlatar rumit.
  • Hasil crop daun berpenyakit dari kebun itulah yang dimasukkan untuk melatih dan menyempurnakan (*fine-tuning*) model EfficientNet-B0!
❓

Pertanyaan 2: Berapa total dataset yang dipakai dan bagaimana pembagiannya?

JAWABAN RINGKAS UNTUK DIPRESENTASIKAN:

Dataset akhir yang digunakan untuk menghasilkan model operasional adalah 32.000 citra, yang merupakan kombinasi seimbang (*Balanced Combined Dataset*) antara dua sumber domain:

1. Dataset Laboratorium (PlantVillage)

20.000 citra

10 kelas penyakit (2.000 citra/kelas seimbang). Daun tunggal dengan latar polos.

2. Dataset Lapangan Nyata (YOLO Crops)

12.000 citra

8 kelas penyakit (1.500 citra/kelas seimbang). Dipotong dari ribuan foto kebun petani.

Pembagian Split Data Standar Machine Learning (80 : 10 : 10):

  • Training Set (80% = 25.600 citra): 16.000 PlantVillage + 9.600 Lapangan. Digunakan untuk melatih bobot model.
  • Validation Set (10% = 3.200 citra): 2.000 PlantVillage + 1.200 Lapangan. Digunakan untuk tuning hyperparameter dan evaluasi tiap epoch.
  • Test Set Independen (10% = 3.200 citra): 2.000 PlantVillage + 1.200 Lapangan. Citra murni yang sama sekali belum pernah dilihat model saat training.

💡 Contekan Menjawab Saat Ditanya Dosen / Penguji

"Kenapa tidak langsung pakai foto lapangan saja sejak awal?"

"Citra PlantVillage sangat kaya variasi (10 kelas lengkap), tetapi tidak mewakili kondisi kebun (*domain shift*). Sebaliknya, data lapangan jumlahnya terbatas dan beberapa kelas sangat sedikit. Solusi terbaik adalah teknik Domain Adaptation (Skema B): model belajar fitur visual dasar dari PlantVillage, kemudian disempurnakan (*fine-tuned*) dengan campuran data lapangan teranotasi agar model akurat di kedua domain."

"Apa bukti bahwa model tidak overfitting pada data training?"

"Kami melakukan Cross-Dataset Evaluation pada Dataset 2 (himpunan citra eksternal yang sama sekali tidak pernah diikutkan dalam proses training). Model baseline lama hanya meraih akurasi 69.16%, sedangkan model final kami melonjak ke 89.18% (+20 poin persen), membuktikan generalisasi fitur yang dipelajari model sangat kokoh."

📖 Panduan Membaca Laporan Evaluasi & Metrik AI

Penjelasan sederhana dan mudah dipahami tanpa rumus rumit

1. Akurasi (Accuracy)

Persentase Kebenaran Total

Artinya: Dari 100 daun yang diperiksa, berapa daun yang ditebak benar oleh AI? Akurasi 96.6% berarti dari 100 daun, ~97 daun ditebak tepat.

2. Precision

Ketepatan Vonis AI

Artinya: Saat AI mendiagnosa daun sebagai "Hawar Daun", seberapa yakin vonis itu benar bukan salah tuduh? Precision tinggi = model jarang memberi alarm palsu (*false alarm*).

3. Recall (Sensitivitas)

Daya Jaring Penyakit

Artinya: Dari seluruh daun yang sebenarnya sakit di kebun, berapa persen yang berhasil ditemukan oleh AI? Recall tinggi = penyakit tidak lolos dari deteksi.

4. F1-Score

Keseimbangan Harmonis

Artinya: Rata-rata harmonis antara Precision dan Recall. Jika F1-Score di atas 90%, artinya model tidak hanya jago menebak, tapi juga tidak pernah salah tuduh.

🧩 Cara Membaca Gambar "Confusion Matrix" (Matriks Kebingungan)

Confusion matrix adalah tabel kotak-kotak yang membandingkan antara Kenyataan Sebenarnya (Baris / Sumbu Y) vs Prediksi Model (Kolom / Sumbu X).

✅ Garis Diagonal Utama (Kiri Atas ke Kanan Bawah):

Angka-angka di garis diagonal menunjukkan prediksi yang BENAR. Semakin gelap warnanya dan semakin besar angkanya, artinya model semakin pintar dan akurat!

⚠️ Kotak di Luar Diagonal (Off-Diagonal):

Menunjukkan kesalahan tebak (kebingungan) model. Misalnya, daun aslinya bercak bakteri tapi model menebak kapang daun. Jika kotak di luar diagonal bernilai 0 atau sangat kecil, model sangat jarang bingung.

Simulasi Baca Baris

Contoh Baris "Healthy" (Daun Sehat) n=200:

Kolom Healthy: 198 (Benar)

Kolom Bercak Kering: 2 (Salah tebak)

Recall = 198 / 200 = 99.0%

Sangat mudah dibaca: cukup lihat apakah angka terpusat di garis diagonal!

Mengapa Target Lapangan Dipatok 1.500 per Kelas?

Kelas terendah pada dataset lapangan YOLO3 (Tungau Laba-laba / Spider Mites) memiliki 1.558 crop bersih. Dengan menetapkan target 1.500 citra/kelas, seluruh kelas dapat dipenuhi 100% menggunakan data asli tanpa perlu duplikasi artifisial (duplication_factor = 1.00).

Mengapa Lapangan Berisi 8 Kelas, Bukan 10 Kelas?

Dataset lapangan Roboflow tidak menyediakan sampel untuk Bacterial Spot dan Target Spot. Namun kedua kelas ini tetap dipertahankan dari PlantVillage sehingga model yang di-deploy tetap mampu mengidentifikasi total 10 kelas penyakit secara utuh.
